## Описание программы
Простое GUI-приложение для генерации случайных задач с фильтрацией по типу (учёба, спорт, работа), сохранением истории в JSON и возможностью добавления новых задач. Используется Python (tkinter, random, json), история сохраняется между запусками.

Примеры использования:
Запустите приложение: python main.py.
Выберите фильтр («все», «учёба», «спорт», «работа»).
Нажмите «Сгенерировать задачу» — задача появится в истории.
Добавьте новую задачу через форму (проверка на пустой ввод).
История сохраняется в tasks.json.

**Автор:** Карина Пузина  
**Вариант:** GitHub User Finder  
**Дата сдачи:** 13.05.2026
 
## Описание программы
GUI-приложение для поиска пользователей GitHub через официальное API. Позволяет искать пользователей по имени/логину, просматривать детальную информацию, добавлять пользователей в избранное и сохранять список избранного в формате JSON. 

## Требования для запуска
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install matplotlib requests`
 
## Как запустить
 
```bash
git clone https://github.com/exxxzi/github-user-finder.git
cd github-user-finder
python main.py

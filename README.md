## Описание программы
Простое GUI-приложение для генерации случайных задач с фильтрацией по типу (учёба, спорт, работа), сохранением истории в JSON и возможностью добавления новых задач. 

## Требования для запуска
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install matplotlib requests`
 
## Как запустить
 
```bash
git clone https://github.com/exxxzi/random-task-generator.git
cd random-task-generator
python main.py
